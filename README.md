# 🎓 Generador de Tribunales de Tesis de Máster

Aplicación web para la asignación y optimización de profesores en tribunales de tesis de Máster.

## 🚀 Despliegue en la Nube (Gratuito)

### Opción 1: Streamlit Community Cloud (Recomendado)
1. Sube este repositorio a **GitHub**.
2. Entra en [share.streamlit.io](https://share.streamlit.io).
3. Conecta tu cuenta de GitHub y selecciona el repositorio.
4. Elige `app.py` como archivo principal y haz clic en **Deploy**.

### Opción 2: Hugging Face Spaces
1. Crea un nuevo Space en [huggingface.co/spaces](https://huggingface.co/spaces).
2. Selecciona **Streamlit** como SDK.
3. Sube los archivos del repositorio.

---

## 🛠️ Instalación Local

```bash
pip install -r requirements.txt
streamlit run app.py
```
